# codexUI

Vue 3 + Vite web app for interacting with Codex/Claude backends.

## Dev Commands

- Dev server: `pnpm dev`
- Build: `npx vite build && npx tsup`
- Test: `npx vitest run`

## Workflow

- Always create a new branch for feature work
- Commit after each discrete task
- Run `/code-review` before merging and iterate on issues found
- TODOs are tracked in `TODO.md` at the repo root
